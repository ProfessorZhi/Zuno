## 背景重建规则

```text
Repo / Git History / Status / Evidence
  → 用户真实面试、历史简历和原始材料
  → 必要公开背景
  → 2–3 个候选解释
  → 用户确认或保持 UNKNOWN
```

可提出研究候选，但不得编造客户、法院采购、上线用户、收入、用户数量或项目需求来源。项目定位只有在“用户—任务—As-Is Workflow—Pain—Required Capability”因果链成立后，才能进入 Architecture Part A。
