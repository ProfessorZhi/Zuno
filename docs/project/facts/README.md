# Project Facts

本目录是 Zuno 项目事实的正式入口，回答：**What actually happened?**

| 文件 | 负责的问题 |
|---|---|
| [`project-background.md`](project-background.md) | 项目来源、用户、痛点、产品立意和合作背景 |
| [`team-and-ownership.md`](team-and-ownership.md) | 团队人数、角色、个人贡献和外部团队边界 |
| [`development-evolution.md`](development-evolution.md) | 第一版、版本演进、需求、评审、发布和回滚 |
| [`delivery-and-usage.md`](delivery-and-usage.md) | 原型、试点、内部测试、生产、用户、运维和指标 |
| [`technology-reality.md`](technology-reality.md) | 实际使用的模型、API/私有部署、微调、数据和基础设施 |

## 事实规则

- 事实来源只能是用户确认、仓库证据、原始项目材料或可直接关联的外部证据；
- `Target Architecture` 不能证明历史实现、上线、用户量、团队分工或个人贡献；
- 记忆不完整时保留 `UNKNOWN`，先研究再提出候选，不强迫猜测；
- `BLUE_PROPOSAL` 和重建候选不能用于简历或生产 Current 叙事；
- 需要指标、运行状态或上线结论时，必须链接 `docs/status/` 或 `docs/evidence/`；
- 红蓝工作区可以攻击和重建，但正式事实最终归本目录和对应 Owner。

详细攻击和候选重建过程见 [`project-red-blue/01-project-facts.md`](../../../project-red-blue/01-project-facts.md)；该文件是红蓝工作材料，不替代本目录的 Canonical Fact。
