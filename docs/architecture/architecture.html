Zuno Target Architecture

六张图分别展示系统上下文、责任域、任务流、事实权威、故障恢复以及部署与演进。它们与 architecture.md 共享同一套 Target，不维护独立的架构真相。

设计对象：9 个逻辑责任域 + Platform / Infrastructure + Optional Context Provider。
物理起点：模块化 Python 后端与按工作负载拆分的 Worker。
实施原则：先稳定事实 Ownership 与恢复语义，再决定数据库、框架和服务拆分。
