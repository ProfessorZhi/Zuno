# 面试模式来源

## 用途

外部面经只能帮助红队生成更接近真实面试的提问角度，不能证明 Zuno 的用户、团队、上线状态或个人贡献。

当前主要来源入口：

- `F:\internship-work\interview\面经\`
- `F:\internship-work\interview\00_面试文案仓库\red-team\`

扫描时优先提炼：连续追问结构、项目背景问题、架构为什么、实现细节、基础原理、失败路径、个人贡献、落地和指标问题；不要把原始面经整批复制进 Zuno。

## 记录方式

每条模式记录：来源文件、岗位或场景、首问、追问方向、面试官试图验证什么、可映射的 D/A 分类。具体公司和个人信息按保密边界处理。
