# Product Thesis Reconstruction

这是产品候选，不是历史事实结论。

## Candidate

```text
WorkBuddy / 通用 Agent Host
    解决 Agent 如何工作

Zuno Candidate
    解决法律案件、证据、专业分析和人工复核如何被建模与追溯
```

## Red Team Falsification

如果 WorkBuddy + 法律 Knowledge + Skill + MCP + Backend 已经能在相同任务、模型、工具和预算下达到同等证据质量，那么 Zuno Runtime 或 Domain Kernel 必须缩减、外部化或删除。

## Required Evidence

产品差异化必须绑定具体任务、不可接受风险和可测结果；不能只凭“法律领域”“Agent 平台”或组件数量成立。
