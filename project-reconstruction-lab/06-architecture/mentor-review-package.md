# Mentor Architecture Review Package

导师或技术负责人评审包建议包含：

1. Project Background：只引用已确认事实。
2. Historical Reality：Current/History/Unknown 分开。
3. Problems Found：事实 Gap 与架构 Gap 分开。
4. Product Thesis：明确可证伪命题。
5. Target Architecture：引用 Canonical Docs，不复制正文。
6. Major Decisions：ADR 与 Decision Candidate。
7. Red Team Objections：最强反对理由。
8. Surviving Design：Counter Attack 后留下的内容。
9. Open Questions：没有证据的地方。
10. Planned Engineering Changes：Architecture-to-Code Gap，不冒充已实现。

输出应专业、可审计，不写成面试背稿。
