# Historical Team and Ownership

正式个人贡献以 [`docs/project/facts/team-and-ownership.md`](../../docs/project/facts/team-and-ownership.md) 为准。

## 可使用的最小叙事

用户是研究生工程参与者，由学硕学长带入一个约 7–8 人核心研发团队，参与 Agent、Memory、OpenViking Memory/Context 和 Tool Calling Strategy。技术负责人、其他后端、算法、前端、测试、部署和客户侧责任仍需分离。

## 不能越界

```text
参与 Agent ≠ 负责整个 Agent Runtime
接入 OpenViking ≠ 实现 OpenViking
查看数据库 ≠ 负责数据库架构
团队完成 Demo ≠ 用户负责交付
```

个人贡献必须继续关联 Git、任务、Artifact 或用户具体记忆。
