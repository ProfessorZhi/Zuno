# Blue Response Template

Blue 对每个 Claim 必须填写：

```text
Problem：
Historical Evidence：
Target Requirement：
Trigger：
Canonical Owner：
State：
Failure：
Retry：
Recovery：
Idempotency：
Security：
Observability：
Test / Benchmark：
Alternative：
Cost：
Decision：KEEP / SIMPLIFY / ADOPT / EXTEND / BUILD / DEFER / DELETE
```

没有历史证据的部分必须写 `UNKNOWN` 或 `TARGET_ONLY`，不能用目标设计补齐历史。
