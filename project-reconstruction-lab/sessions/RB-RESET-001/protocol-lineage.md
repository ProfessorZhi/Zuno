# Protocol Lineage

```text
V2
  → V3
  → V3.1 / V3.1.2 / V3.1.3
  → V4
  → V4.1
  → V4.2
```

## 解释

- V2：第一代 100Q 和基础 Red/Blue 记录契约；
- V3：Question、Answer、Score、Decision、Delta 和 Canonical Sync；
- V3.1 系列：Part A/Part B、文档质量、Human Writing、Closure Classification；
- V4：Fresh Context、Dual Thread、Artifact Handoff 等工作流隔离；
- V4.1：Interview Calibration、Part-A Cold Start 和更严格的解释性要求；
- V4.2：Batch/Live Profile 与 Adaptive Interrogation 的实验性工作流。

Blue Repair、Evidence Closure、P0 V4 Execution、Gate Realignment 和 Semantic Audit 是围绕
历史 Round 的专项轨道，不构成下一代 active Protocol。

所有节点均保留原始 Session 和可追溯文档。Lineage 只用于解释“规则从哪里来”，不把旧规则
传递到 `ACTIVE_PROTOCOL: NONE` 之后。
