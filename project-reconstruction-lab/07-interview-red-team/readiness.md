# Interview Readiness

## Interview Ready

用户能够在事实边界内解释：

```text
Why
How
State
Failure
Tradeoff
Alternative
Personal Ownership
```

## Not Production Ready

Interview Ready 不代表：

```text
Load Test
E2E
Fault Injection
Security Evidence
DR
Runtime Evidence
Production Evidence
```

这些仍由 `docs/facts/`、`docs/evidence/` 和实际运行证据决定。
