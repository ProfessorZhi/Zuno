# Zuno Agent References

`.agent/references/` 只保存当前可复用的 Agent 工作规则，不保存旧 Program、
旧施工计划、thread prompt 或架构正文。

- `workflow.md`：任务执行、验证、提交和推送。
- `task-routing.md`：按任务本质选择入口和 owner。
- `code-map.md`：当前代码 owner 和调用边界。
- `docs-map.md`：正式文档与 evidence 路由。
- `verification-map.md`：当前 verifier 与 focused tests。
- `debugging.md`：根因定位和禁止的调试捷径。
- `known-pitfalls.md`：已确认的长期坑点。
- `current-program.md`：无 active program，旧 Program1 已 retired。
