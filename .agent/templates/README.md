# Agent Templates

模板只保存输出骨架，不保存项目历史、旧施工状态或架构正文。

- `requirement-intake.md`：目标、边界和停止条件。
- `readonly-audit-prompt.md`：只读盘点。
- `spec-coding-checklist.md`：实现前 contract checklist。
- `verification-report-template.md`：验证回执。
- `goal-mode-prompt.md` / `target-mode-prompt.md`：任务执行提示词骨架。
- `mermaid-diagram-template.md`：图源骨架。
